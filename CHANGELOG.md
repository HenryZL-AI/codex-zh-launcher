# Changelog

## 0.1.0 - 2026-10-15

- Initial experimental source release with a separate user-level macOS launcher.
- Read-only official signature and translation-resource check.
- Empty-profile Chinese sidebar verification tied to exact build hashes.
- Narrow runtime translation adapter and private pipe, without app patching.
- Owned-file installation, collision protection and conservative uninstall.
- Chinese/English documentation and release-content checks.
- No automatic quit, background recovery, task scanning or model calls.
